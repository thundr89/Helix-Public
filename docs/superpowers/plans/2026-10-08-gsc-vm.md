# GSC Stack VM Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `gsc_vm_exec` compiles one GSC file to bytecode and runs it on a stack machine so map and gametype `main` can reach the existing weapon, team, ambient, and gametype hooks through real expressions.

**Architecture:** `compile.c` lowers a file's functions into one `GscProg` (instruction stream, string table, function table). `vm.c` executes that program with a value stack and a frame per call, then deletes the program. `GscHost` stays the only way out to the game. `gsc_read` is not this machine.

**Tech Stack:** C, CMake, MinGW (`/c/msys64/mingw64/bin` on `PATH`), `./build/hxfs_cod_test.exe` from `C:\Users\tothd\Desktop\Helix-Public`.

## Global Constraints

- Entry points stay `gsc_vm_exec` and `gsc_vm_scan_weapons` in `src/cod/gsc/vm.h`. `GscHost` fields stay `read_file`, `ambient`, `give_weapon`, `take_weapons`, `set_team_names`, `set_gametype`.
- Parameters bind by position. A missing argument is `undefined`. Extra arguments are dropped. Call depth stops at 32.
- `thread` runs the call once, inline. `wait` and `waittill` stop that branch. The caller continues. Collected host calls remain.
- An entity call, a `self` method, or `getent` stops that branch the same way. `gsc_vm_exec` still returns 1 when `main` was found and started.
- Fuel exhaustion stops the whole run and `gsc_vm_exec` returns 0.
- Integer literals wrap modulo 2^32 into a signed 32-bit value. `2147483648` is `INT_MIN`.
- `src/cod2003` stays unchanged. `gsc_read`, `gsc_to_helix`, and `gsc_allied_body` stay unchanged. `COD_CACHE_REV` stays unchanged.
- Commit a Helix-Public task only when the user asked for commits in that execution. Never commit the idTech3-4 tree. The commit commands below are the messages to use when a commit is asked for.
- Build with `export PATH="/c/msys64/mingw64/bin:$PATH"`.

```c
typedef enum GscOp {
    GSC_RETURN = 1,
    GSC_PUSH_UNDEF,
    GSC_PUSH_INT,
    GSC_PUSH_FLOAT,
    GSC_PUSH_STR,
    GSC_GET_LOCAL,
    GSC_SET_LOCAL,
    GSC_ADD, GSC_SUB, GSC_MUL, GSC_DIV,
    GSC_LT, GSC_EQ,
    GSC_JUMP, GSC_JUMP_IF_FALSE,
    GSC_CALL,    /* a = function index, b = argc */
    GSC_BUILTIN  /* a = builtin id, b = argc */
} GscOp;

enum { GSC_BU_GIVE = 1, GSC_BU_TAKE, GSC_BU_AMBIENT, GSC_BU_GAMETYPE, GSC_BU_ALLIES, GSC_BU_AXIS };

typedef struct GscIns {
    unsigned char op;
    int a, b;
    int str; /* string-table index, or -1 */
    double f;
} GscIns;

typedef struct GscFunc {
    char name[64];
    int entry;
    int nparams;
    int nlocals;
} GscFunc;

typedef struct GscProg {
    GscIns* code;
    int ncode, cap;
    GscFunc* funcs;
    int nfunc, fcap;
    char* strs;
    int* stroff;
    int nstr, scap;
    int fuel;
} GscProg;

/* Returns 1 and fills prog. Caller frees with gsc_prog_free. */
int gsc_compile(const char* source, size_t size, GscProg* prog);
void gsc_prog_free(GscProg* prog);
```

`gsc_vm_exec` compiles, runs `func`, frees the program, and returns 1 when that function existed. Fuel starts at 100000.

- [ ] **Step 3: Write the machine**

Add `src/cod/gsc/compile.c` to `HXFS_COD_SOURCES` next to `src/cod/gsc/vm.c`, and to `add_library(cod_sgame SHARED ...)` so the server module still links.

`op.h` is the enums and structs from the Interfaces block. `compile.h` declares `gsc_compile` and `gsc_prog_free`.

`gsc_compile` strips `//` comments, finds `name(...) { ... }` functions the way `index_funcs` does today, and compiles each body. For this task the body grammar is: `return <expr>;`, `if (<expr>) return <expr>;`, `<ident> = <expr>;`, and expression calls. Expressions are integers, identifiers, `+ - * /`, parentheses, `<`, and calls of the form `name(expr, ...)`. String literals compile to `GSC_PUSH_STR`.

Emit `GSC_BUILTIN` for `giveWeapon` (`GSC_BU_GIVE`), `takeWeapon` and `takeAllWeapons` (`GSC_BU_TAKE`), `ambientPlay` (`GSC_BU_AMBIENT`). `level.gametype = "..."` and `level.gamemode = "..."` emit `GSC_BU_GAMETYPE` with the string. `game["allies"] = "..."` and `game["axis"] = "..."` emit `GSC_BU_ALLIES` and `GSC_BU_AXIS`.

Locals are the parameters in order, then assigned names. `GET_LOCAL` / `SET_LOCAL` use that slot. A call whose name is a function in this file is `GSC_CALL`. Integer literals use `strtol` then cast through `uint32_t` into `int32_t`.

`vm.c` deletes the statement walker. `gsc_vm_exec` calls `gsc_compile`, looks up `func`, and runs from `entry` with fuel `100000` and depth 0. `GSC_CALL` pushes a frame of `nlocals` undefined slots, copies `min(argc, nparams)` arguments, and runs until `GSC_RETURN`. Depth 32 returns from that call with `undefined` and does not abort the caller. `GSC_BUILTIN` pops `b` arguments and calls the matching `GscHost` function when the host pointer is non-NULL. `GSC_ADD` on two ints pushes the sum; on a float and a number it pushes a float. `gsc_vm_last_int` is set from an int return of the entry function. `gsc_vm_scan_weapons` stays as it is.
