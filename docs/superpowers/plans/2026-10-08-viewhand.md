# Viewhand Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** First person shows the Wehrmacht hands holding an MP44 bolted to `tag_weapon`, in bind pose.

**Architecture:** The plugin bakes `tag_weapon` from `xmodelparts`, permutes it into the same view basis as the OBJ vertices, and serves `cod/viewhand.txt`. Helix loads both xmodels without a second barrel rotation, draws the hands on the eye basis at scale 1, and draws the gun as parent times that tag.

**Tech Stack:** C, C++, CMake, MinGW (`/c/msys64/mingw64/bin` on `PATH`), `hxfs_cod_test`, `helix.exe --test`.

## Global Constraints

- Hands path is `xmodel/viewmodel_hands_whermact`. Gun path is `xmodel/viewmodel_mp44`. The text name is `cod/viewhand.txt`.
- `P(x, y, z) = (-y, z, x)`. `P⁻¹(a, b, c) = (c, -a, b)`. Translation is `P t`. Rotation is `P R P⁻¹`. Model +Y maps to -right.
- The twelve floats are column-major `Mat4::from_axes` order: X, Y, Z, then translation.
- The 90° CoD-Z case with translation `(1, 2, 3)` prints `0 0 1 0 1 0 -1 0 0 -2 3 1`. Model +Y maps to -right.
- Viewhand parent scale is 1 and stays on the eye. Hip fire is `tag_torso` baked from `viewmodel_mp44_ADS_up` frame 0. It does not use the stock `7.4` / `4.25` / `-2.75` or `0.46`.
- Parent position, with kick `k`, reload fraction `ru`, and phase `bob`:

```
eye
+ forward * (-k * 0.52 - ru * 2.4)
+ right * sin(bob) * 0.32
+ up * (cos(bob * 2) * 0.14 + k * 0.22 - ru * 4.5)
```

- Axes are right, up, forward. Gun matrix is `parent * tag` for every gun group.
- `orient_barrel_to_z` does not run on these meshes. A missing text, tag, hand mesh, or gun mesh keeps the stock viewmodel. One of the pair alone is not drawn.
- Shot, sound, and third person stay on the equipped Helix weapon. No xanim, no weapon switch, no GSC.
- `src/cod2003` stays unchanged. `COD_CACHE_REV` stays unchanged.
- Commit a Helix-Public task only when the user asked for commits in that execution. Never commit the idTech3-4 tree. The commit commands below are the messages to use when a commit is asked for.
- Build with `export PATH="/c/msys64/mingw64/bin:$PATH"`.

int cod_view_basis_rigid(const float cod_axes[9], const float cod_trans[3], float out[12]) {
    const float* cx;
    const float* cy;
    const float* cz;
    if (!cod_axes || !cod_trans || !out) return 0;
    cx = cod_axes;
    cy = cod_axes + 3;
    cz = cod_axes + 6;
    out[0] = cy[1]; out[1] = cy[2]; out[2] = cy[0];
    out[3] = cz[1]; out[4] = cz[2]; out[5] = cz[0];
    out[6] = cx[1]; out[7] = cx[2]; out[8] = cx[0];
    out[9] = cod_trans[1];
    out[10] = cod_trans[2];
    out[11] = cod_trans[0];
    return 1;
}

- [ ] **Step 3: Write the minimal implementation**

Declare `cod_xmodel_view_tag` in `read.h`. In `read.c`, after the bones are baked, walk `rootCount + childCount` names starting at byte `6 + childCount * 19`. Each entry is a NUL-terminated name and then 24 bytes. Those 24 bytes are not the pose. The matching index selects `worlds[index]`. Build the CoD columns with `quat_rot` on `(1,0,0)`, `(0,1,0)`, and `(0,0,1)`, then call `cod_view_basis_rigid`.

```c
int cod_xmodel_view_tag(const void* parts, size_t size, const char* name, float out[12]) {
    const unsigned char* p = (const unsigned char*)parts;
    CoD1Bone* locals = NULL;
    CoD1Bone* worlds = NULL;
    unsigned short num_bones = 0;
    unsigned short ver = 0, child_count = 0, root_count = 0;
    size_t off = 0;
    int i, found = -1;
    float axes[9];
    float ex[3] = {1.f, 0.f, 0.f};
    float ey[3] = {0.f, 1.f, 0.f};
    float ez[3] = {0.f, 0.f, 1.f};
    float rx[3], ry[3], rz[3];
    if (!p || !name || !name[0] || !out) return 0;
    if (!cod_xmodel_load_bones(p, size, &locals, &worlds, &num_bones)) return 0;
    if (!ru16(p, size, &off, &ver) || !ru16(p, size, &off, &child_count) ||
        !ru16(p, size, &off, &root_count)) {
        free(locals);
        free(worlds);
        return 0;
    }
    off = 6 + (size_t)child_count * 19;
    for (i = 0; i < (int)num_bones; i++) {
        char bone[64];
        size_t n = 0;
        if (off >= size) break;
        while (off < size && p[off] != 0 && n + 1 < sizeof(bone)) bone[n++] = (char)p[off++];
        bone[n] = '\0';
        if (off >= size || p[off] != 0) break;
        off++;
        if (off + 24 > size) break;
        off += 24;
        if (strcmp(bone, name) == 0) found = i;
    }
    if (found < 0) {
        free(locals);
        free(worlds);
        return 0;
    }
    quat_rot(worlds[found].q, ex, rx);
    quat_rot(worlds[found].q, ey, ry);
    quat_rot(worlds[found].q, ez, rz);
    axes[0] = rx[0]; axes[1] = rx[1]; axes[2] = rx[2];
    axes[3] = ry[0]; axes[4] = ry[1]; axes[5] = ry[2];
    axes[6] = rz[0]; axes[7] = rz[1]; axes[8] = rz[2];
    cod_view_basis_rigid(axes, worlds[found].trans, out);
    free(locals);
    free(worlds);
    return 1;
}
```

```cpp
Mat4 viewhand_transform(Vec3 eye, Angles ang, float bob_phase, float kick, float reload_u) {
    Vec3 f, r, u;
    ang.to_vectors(&f, &r, &u);
    const float k = kick < 0.f ? 0.f : kick;
    const float ru = reload_u < 0.f ? 0.f : (reload_u > 1.f ? 1.f : reload_u);
    const Vec3 pos = eye + f * (-k * 0.52f - ru * 2.4f) + r * (std::sin(bob_phase) * 0.32f) +
                     u * (std::cos(bob_phase * 2.f) * 0.14f + k * 0.22f - ru * 4.5f);
    return Mat4::from_axes(r, u, f, pos);
}
```
